# 사용법과 문제 해결

## 실행 전 준비

- Windows 64비트와 .NET Framework 4.8을 사용합니다.
- Aside 브라우저가 설치되어 있고, 바탕화면이나 시작 메뉴에 Aside 바로가기가 있어야 합니다.
- 평소 Aside를 사용하는 동일한 관리자 계정으로 실행합니다. 다른 관리자 계정의 자격 증명을 입력하면 그 계정에 적용됩니다.

## 로고 변경

`Aside-Logo-Apply.exe`를 실행하고 Windows 관리자 승인창에서 승인합니다. 설치 마법사와 완료 확인창 없이 바탕화면·시작 메뉴·고정 작업표시줄·실행 중인 Aside 창에 적용합니다.

다크 모드에는 화이트, 밝은 모드에는 블랙 로고를 사용합니다. Windows의 사용자 지정 모드에서는 작업표시줄에 적용되는 **Windows 모드**를 따릅니다.

테마 전환, Aside 재실행, Windows 로그인 후에도 로고를 유지하도록 작은 도우미와 로그인 작업을 사용합니다. 도구를 휴대용으로 실행하고 끝내는 방식은 아닙니다. 앱 목록에는 등록하지 않으며 자동 업데이트 기능은 없습니다.

아이콘 파일과 최초 원본 백업은 `%ProgramFiles%\Aside Clean Logo`에 보관합니다. 다운로드한 변경 파일을 옮기거나 삭제해도 아이콘 경로가 깨지지 않습니다.

## 원래 로고로 복원

`Aside-Logo-Restore.exe`를 실행하고 관리자 승인을 합니다. 원래 바로가기와 실행 중 창의 아이콘을 복원하고, 이 도구가 만든 도우미·로그인 작업·아이콘 파일을 제거합니다.

이미 복원된 PC에서 복원 파일을 다시 실행해도 추가 변경은 하지 않습니다. 원본 백업이 있어야 정확히 복원할 수 있으므로 백업 폴더를 직접 지우지 마세요. 복원 파일을 잃어버리면 [최신 릴리스](https://github.com/contentriumkorea/aside-clean-logo/releases/latest)에서 다시 받을 수 있습니다.

## 기존 Setup 버전에서 전환

기존 도우미를 별도로 삭제하지 않고 원클릭 변경 파일을 실행하면 됩니다. 최초 원본 백업을 유지하면서 전환하고 앱 목록의 기존 등록을 제거합니다. 이후에는 복원 파일로 되돌립니다.

## 아이콘이 바로 바뀌지 않을 때

Windows 아이콘 캐시나 실행 중인 창의 상태에 따라 표시가 잠시 늦어질 수 있습니다. 바탕화면을 새로 고치고 잠시 기다린 후 확인하세요. 계속 바뀌지 않으면 변경 파일을 다시 실행합니다. 도구는 Explorer나 Aside를 강제로 종료하지 않습니다.

오류가 나면 오류창 내용을 확인하세요. 파일이 있는 경우 `%ProgramFiles%\Aside Clean Logo\status.json`과 `last-error.txt`에서 진단 정보를 확인할 수 있습니다. 문제를 공유할 때는 사용자 이름과 개인 경로 등 비공개 정보를 가리세요.

## 지원 범위와 검증

배포는 Windows 전용입니다. Windows 시험 환경에서 기존 Setup 전환, 새 적용, 다크·라이트 전환, 반복 적용, 원본 바로가기 복원, 반복 복원, 도우미 제거를 확인합니다. 시험 환경의 통과가 모든 Windows 사용자 설정에서 동일한 화면 표시를 보장하지는 않습니다.

각 릴리스의 `SHA256SUMS.txt`로 다운로드 파일의 SHA-256을 비교할 수 있습니다. GitHub가 자동으로 제공하는 Source code ZIP은 실행 파일 묶음이 아닙니다.
