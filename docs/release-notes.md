Clean, tightly cropped black and white Aside icons with a preserved central sparkle and thinner surrounding lines.

- **Windows:** native Setup executable; install button; administrator approval; system appearance switching for desktop, Start menu, taskbar shortcuts and running browser windows. Original icon backups and restoration on removal.
- **macOS:** universal Apple Silicon/Intel installer disk image; install button; a managed Desktop Finder alias with appearance-aware icons; reversible installation. macOS 12+.

Aside must already be installed. Neither installer modifies the browser executable, profile, login, bookmarks or history.

macOS changes its managed Desktop shortcut only; the original application and its Dock icon remain untouched. The macOS utility is ad-hoc signed and not notarized; use normal macOS approval if required. Native fixture tests verify alias apply/restore and original app signature preservation; live Aside behavior is not hardware-verified.
