Windows용 로고 변경·원복 파일 두 개로 간단하게 적용합니다.

- **Aside-Logo-Apply.exe**: 실행 → 관리자 승인 → 로고 변경. 설치 화면과 완료 확인창이 없으며 앱 목록에 등록하지 않습니다.
- **Aside-Logo-Restore.exe**: 원래 로고를 복원하고 도우미·로그인 작업·아이콘 파일을 제거합니다.

바탕화면·시작 메뉴·고정 작업표시줄·실행 중 Aside 창에 적용합니다. 다크 모드에는 화이트, 밝은 모드에는 블랙 로고로 자동 전환합니다. 재실행 후에도 유지하려고 작은 백그라운드 도우미를 사용하며 원복 시 함께 제거합니다.

기존 Setup 사용자도 변경 파일을 실행하면 이전 원본 백업을 유지하면서 전환됩니다. Aside 본체와 사용자 데이터는 변경하지 않습니다. 맥 배포는 취소했으며 이 릴리스는 Windows 전용입니다.

Two one-click Windows tools replace the setup wizard. Apply keeps the approved icons consistent through a protected helper; Restore returns the original icons and removes that helper. No Installed Apps entry is created. Original browser files and profile data are preserved.
