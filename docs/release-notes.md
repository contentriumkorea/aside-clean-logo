Clean, tightly cropped black and white Aside icons with a preserved central sparkle and thinner surrounding lines.

- **Windows:** native Setup executable; install button; administrator approval; system appearance switching for desktop, Start menu, taskbar shortcuts and running browser windows. Original icon backups and restoration on removal.
- **macOS:** distribution on hold. There is no supported installer for the actual running Aside Dock tile yet; no macOS installer is attached to this release.

Aside must already be installed. The Windows installer preserves the browser executable, profile, login, bookmarks and history.

An isolated macOS experiment changed the real running Dock tile, but the production connection is blocked by Keychain entitlement error `-34018` outside Aside. This requires a supported first-party integration and is not fixed by administrator approval.

Download **Aside-Clean-Logo-Windows-Setup.exe** below. `SHA256SUMS.txt` verifies the release file.
