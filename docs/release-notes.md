**어사이드 아이콘을 더 깔끔하게. 변경도, 원복도 한 번 실행으로.**

Windows 원클릭 변경·복원 방식은 유지하면서 프로젝트 커버, 다운로드 안내와 사용 예시를 정리했습니다.

| 다운로드 | 용도 |
| --- | --- |
| [로고 변경 — Aside-Logo-Apply.exe](https://github.com/contentriumkorea/aside-clean-logo/releases/download/v1.1.1/Aside-Logo-Apply.exe) | 테두리 없는 로고 적용. 다크 모드는 화이트, 밝은 모드는 블랙으로 전환합니다. |
| [원래 로고 복원 — Aside-Logo-Restore.exe](https://github.com/contentriumkorea/aside-clean-logo/releases/download/v1.1.1/Aside-Logo-Restore.exe) | 최초 원본 아이콘으로 복원하고 도우미와 자동 실행을 제거합니다. |

두 파일을 받아 두고, 필요한 파일을 실행해 Windows 관리자 승인을 하면 됩니다. 설치 마법사와 완료 확인창이 없으며 앱 목록에도 등록하지 않습니다.

테마 전환과 Aside 재실행 후 유지를 위해 작은 백그라운드 도우미를 사용하며 원복할 때 함께 제거합니다. Aside 본체와 로그인·북마크·방문 기록은 변경하지 않습니다.

**필요 환경:** Windows 64비트, 설치된 Aside, .NET Framework 4.8. 평소 Aside를 사용하는 동일한 관리자 계정으로 실행하세요.

[자세한 사용법과 문제 해결](https://github.com/contentriumkorea/aside-clean-logo/blob/v1.1.1/docs/usage.md) · 첨부된 `SHA256SUMS.txt`로 파일 무결성을 확인할 수 있습니다.

비공식 사용자화 도구이며 Aside와 제휴한 제품이 아닙니다. 로고 권리는 각 권리자에게 있습니다.
